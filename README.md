# SharpSpeak - AI English Tutor 

SharpSpeak is an interactive Android application designed to help users practice and improve their English skills using AI. Powered by the Google Gemini API, it provides real-time conversations, speech-to-text, TTS voice feedback, and dynamic vocabulary training.

##  Key Features
* **Smart AI Chat:** Context-aware English practice powered by Gemini AI.
* **Voice Capabilities:** Built-in `SpeechRecognizer` for voice input and custom-pitched `TextToSpeech` (TTS) for natural responses.
* **Dynamic Chat UI:** Clean bubble-style interface using `RecyclerView`.
* **Random Vocabulary Generator:** Quick-action button to fetch random B1/B2 English vocabulary with Arabic translations and example sentences.
* **Secure API Handling:** API keys are isolated safely using `local.properties` and `BuildConfig`.

##  Tech Stack
* **Language:** Java & Kotlin DSL (Gradle)
* **AI Engine:** Google Generative AI SDK (Gemini)
* **UI & Architecture:** Material Design, RecyclerView, ViewBinding
* **Networking:** OkHttp & Coroutines
